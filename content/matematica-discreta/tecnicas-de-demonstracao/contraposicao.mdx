Em alguns casos, produzir uma demonstração direta de uma conjectura
$P \Rightarrow Q$ é um trabalho árduo. Assim, você pode demonstrar o teorema
$P \Rightarrow Q$ pelo uso da tautologia:

$$
(\lnot Q \Rightarrow \lnot P) \Rightarrow (P \Rightarrow Q)
$$

Lembre-se que $\lnot Q \Rightarrow \lnot P$ é a **contrapositiva** de
$P \Rightarrow Q$.

## Exemplos

- Se o Botafogo venceu o Treze, então ele foi campeão paraibano.
  Contrapositiva: se o Botafogo não foi campeão do campeonato paraibano, então
  ele não venceu o Treze.
- Se $2 + 3 = 5$, então $2 + 3 + 7 = 5 + 7$. Contrapositiva: se
  $2 + 3 + 7 \ne 5 + 7$, então $2 + 3 \ne 5$.

A técnica para demonstrar que $P \Rightarrow Q$ construindo uma prova direta de
$\lnot Q \Rightarrow \lnot P$ é chamada de **demonstração por contraposição**.

<Callout type="tip" title="Quando usar contraposição">
  É útil quando a hipótese $P$ é "fácil de negar mas difícil de usar
  diretamente", enquanto a tese negada $\lnot Q$ dá algo concreto para
  manipular algebricamente. É o caso do exercício 2 abaixo: partir de "$x^2$
  é ímpar" não dá um ponto de partida algébrico óbvio, mas partir de "$x$ é
  par" ($\lnot Q$) dá direto $x = 2m$.
</Callout>

O roteiro é o mesmo da [demonstração direta](/docs/matematica-discreta/tecnicas-de-demonstracao/direta),
só que aplicado a $\lnot Q \Rightarrow \lnot P$ em vez de $P \Rightarrow Q$:

1. Escreva $\lnot Q$ algebricamente (negando a tese original).
2. Deduza, passo a passo, a forma algébrica de $\lnot P$.
3. Conclua $\lnot Q \Rightarrow \lnot P$ e invoque a tautologia acima para
   obter $P \Rightarrow Q$.

## Exercícios

<Exercise>
Mostre por contraposição que, se um número inteiro é divisível por $6$, então ele
também é divisível por $3$.

<Answer>
$P$: "$x$ é divisível por $6$" &nbsp; $Q$: "$x$ é divisível por $3$".

**Contrapositiva ($\lnot Q \Rightarrow \lnot P$):** se $x$ **não** é
divisível por $3$, então $x$ **não** é divisível por $6$.

Provamos essa versão diretamente: se $x$ não é divisível por $3$, então em
particular $x$ não pode ser escrito como $x = 6m = 3(2m)$ para nenhum
$m \in \mathbb{Z}$ (pois isso o tornaria divisível por $3$). Logo $x$ não é
divisível por $6$, ou seja, $\lnot Q \Rightarrow \lnot P$. Pela tautologia,
$P \Rightarrow Q$. $\blacksquare$

</Answer>
</Exercise>

<Exercise>
Mostre que, se o quadrado de um número é ímpar, então o número também é ímpar.

<Answer>
**Hipótese:** $x^{2} = 2k + 1$, $k \in \mathbb{Z}$. &nbsp; **Tese:** $x = 2m + 1$,
$m \in \mathbb{Z}$.

Por contraposição, temos que $x = 2m$, com $m \in \mathbb{Z}$. Assim
$x^{2} = (2m)^{2} = 4m^{2} = 2(2m^{2})$. Logo $x^{2}$ é par. Assim
$\lnot Q \Rightarrow \lnot P$. Logo a afirmação é verdadeira. $\blacksquare$

</Answer>
</Exercise>

<Exercise>
Mostre que, se $m$ é um número ímpar, então $3m + 9$ é par.

<Answer>
**Hipótese:** $m = 2k + 1$, $k \in \mathbb{Z}$.

Por contraposição, supomos $3m + 9$ ímpar e concluímos que $m$ é par: se $m = 2k$,
então $3m + 9 = 3(2k) + 9 = 6k + 9 = 2(3k + 4) + 1$, ímpar. Assim
$\lnot Q \Rightarrow \lnot P$, e a afirmação é verdadeira. $\blacksquare$

</Answer>
</Exercise>

<Exercise>
Mostre que a soma de um número par com um número ímpar é um número ímpar.

<Answer>
**Hipótese:** $x = 2k$ e $y = 2m + 1$, com $k, m \in \mathbb{Z}$.

$x + y = 2k + (2m + 1) = 2(k + m) + 1$, que é ímpar. $\blacksquare$

Note que esta prova é **direta**, não por contraposição: aqui a hipótese
$P$ é composta ("$x$ par **e** $y$ ímpar"), e negar uma conjunção produz uma
disjunção ($x$ ímpar **ou** $y$ par) que não simplifica a álgebra — a prova
direta já é natural. Contraposição vale a pena quando negar a *tese* dá algo
mais fácil de manipular do que a hipótese original, como nos exercícios
anteriores.

</Answer>
</Exercise>
